# Как устроен диплом системного администратора

Учебное пособие Анны Смаги. Практический стенд в Яндекс Облаке, октябрь 2026.

[Открыть всю книгу в браузере](handbook.html) — скачайте файл и откройте локально. Для PDF используйте печать браузера. [30 карточек для повторения](cards.csv).

Это книга для человека, который впервые видит облачную инфраструктуру. Читайте части по порядку. Не копируйте команды изолированно: сначала установите, на какой машине команда должна выполняться, затем поймите её действие, потом проверьте результат. Команды изменения инфраструктуры могут расходовать деньги или уничтожать данные; упражнения с остановкой nginx выполняйте только на учебном стенде.

Цель — уметь объяснить каждую стрелку на схеме и восстановить работоспособность после типичной ошибки. Наличие шести работающих ВМ само по себе не означает, что диплом готов: нужны реальные метрики, документы логов, резервные копии и проверка отказа.

Практический источник книги — код данного проекта и требования диплома, а не вымышленные примеры вакансий. Ответы на вопросы по защите приведены в каждой части. Для повторения используйте `cards.csv`.
