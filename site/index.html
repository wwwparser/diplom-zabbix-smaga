Анна Смага · Системное администрирование

Сайт продолжает работать,
когда один сервер недоступен.

Учебная инфраструктура в Яндекс Облаке: два nginx в разных зонах, балансировщик, наблюдаемость и резервное копирование.

01 / Доступность
Application Load Balancer направляет запросы только на исправные серверы.
02 / Наблюдаемость
Zabbix собирает метрики. Filebeat отправляет журналы nginx в Elasticsearch, Kibana помогает их исследовать.
03 / Восстановление
Ежедневные снимки дисков сохраняются семь дней.
